This project was done for an assignment, submitted in parts through commits with a provided set of media files and completed in increments.
The project included choosing a client from a provided set, which I chose the "North Star Bakery"
This repo encapsulates a very basic responsive, mobile-first website for North Star Bakery with semantic HTML structure, an external stylesheet utilizing the flexbox model & media queries, and JavScript features that use browser local storage for saving user selection
